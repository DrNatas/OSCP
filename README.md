Open **this repository root** as the Obsidian vault so the two content folders, `OSCP/` and `Writeups/`, are available together. Markdown links also work in VS Code and GitHub. All HTB and practice notes are cataloged in the root [machine writeups index](Writeups/00-HTB-Solutions-Index.md) and stored under `Writeups/`.

Reusable commands live in `OSCP/Reference/`; reusable attack patterns live inside the numbered phase folders; phase decisions live in the eight numbered folders under `OSCP/`; machine-specific outputs stay with their writeups. Put new screenshots in an `images/` folder beside the note and link to them with a relative Markdown image path.
