Reusable commands live in `OSCP/Reference/`; decision checklists live in `OSCP/Methodology/`; machine-specific outputs stay with their writeups. Put new screenshots in an `images/` folder beside the note and use a relative link, for example `![Initial access](images/01-initial-access.png)`.
